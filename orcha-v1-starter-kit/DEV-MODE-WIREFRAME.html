AThree options, never binary. A yes/no gate pushes people to yes; a third path keeps refusal cheap.
BORCHA_APPROVAL_MODE=consequential-only is the posture these gates implement — and the most important unimplemented line in the repo.
CConsumer mode shows the same gate in plain English, with the capability name removed.
