# Roadmap

## V1 — Autonomous software-building company

Goal-to-plan onboarding, persistent VM runtime, bounded agent team, repo/build/test/preview loop, real event-driven Live HQ, activity feed, memory, file tiers, Studio inspection, recovery, cost guardrails, and evaluation-backed experiments.

## V1.5 — Operated product loop

Instrument real preview usage, add support and analytics roles, scheduled maintenance, richer memory retrieval, external email behind explicit grants, and stronger multi-company isolation.

## V2 — Company operating system

Reusable Company DNA, agent/workflow version marketplace, domain-specific templates, richer Evolution trees, collaborative human leadership, and production deployment adapters.

## Later / gated

Real-world business operations, payments, external account actions, and broader self-modification. These require separate risk reviews, capability design, legal review, and high-confidence evaluation.
