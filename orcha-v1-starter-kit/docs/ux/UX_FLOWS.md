# Consumer UX Flows

## Onboarding

1. Hero: “What do you want your company to accomplish?”
2. Intent cards: Build a Product, Grow My Business, Automate My Work, Research an Opportunity, Start From an Idea.
3. Goal input plus optional constraints: audience, deadline, budget, existing assets.
4. Plain-language Company Plan: objective, first milestone, team, assumptions, permissions, expected outputs.
5. Start Company. Ordinary internal work does not require repeated approval.

## Company home

Show Current Objective, Progress, Active Team, Live HQ, Experiments, Results, Assets, Cost, and Timeline. Default language is outcome-oriented; raw logs live in Studio.

## Live HQ

Center node: Orchestrator. Outer nodes: active roles. Edges represent real task dispatch, message, artifact handoff, or dependency. Node cards show doing, why, files changed, tools used, and outcome. Idle agents should be visibly idle, not theatrically busy.

## Evolution

Branching tree of baseline and variants. Each node shows metric, confidence/measurement status, cost, reliability, and decision. “Promote” requires a policy check; “Rollback” is always available.

## While You Were Away

Summarize only recorded events since the last seen cursor: shipped previews, completed tasks, failures repaired, experiments decided, new questions, and next actions.

## Studio

Tabs: Agents, Prompts, Tools, Workflows, Files, Environment, Permissions, Logs, VM, Evaluations. Studio is inspect-first; destructive or externally consequential actions remain gated.
