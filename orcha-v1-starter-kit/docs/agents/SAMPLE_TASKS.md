# Sample Tasks

## Build a product slice

Objective: launch a study-material summarizer preview.

Acceptance: upload a text file, summarize it, show source name and word count, handle empty input, include a basic test, and create a preview artifact.

## Research competitor feedback

Produce a cited table of recurring complaints from approved public sources. Do not create accounts or submit forms.

## Evolution experiment

Compare onboarding copy A/B in a local preview using a fixed synthetic task set. Score completion, clarity, and regression rate. Do not call the result “conversion” unless real instrumented users exist.

## Recovery task

When a build fails, capture the failing command and environment, attempt a dependency or code fix in a branch, rerun tests, and emit a recovery summary.
